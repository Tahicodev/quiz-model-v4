# Global Search - Quick Start Guide

## 🚀 Getting Started

Your global search is **ready to use**! No additional setup needed.

## 🔍 How to Search

### Method 1: Click the Search Bar

```
Click the search input in the header that says "Search anything... (Cmd+K)"
```

### Method 2: Keyboard Shortcut

```
Press Cmd+K (Mac) or Ctrl+K (Windows/Linux)
```

## 💡 What You Can Search

| What           | Search By                      | Example                      |
| -------------- | ------------------------------ | ---------------------------- |
| **Questions**  | Question text, options, answer | "What is Windows", "Alt+Tab" |
| **Categories** | Category name                  | "Biology", "OS Fundamentals" |
| **Exams**      | Exam name, description         | "Final Exam", "Midterm"      |
| **Classes**    | Class name                     | "Class A", "Advanced"        |
| **Results**    | Student name or ID             | "John", "2024001"            |

## ⚡ Search Results

Once you search:

1. Results appear grouped by type below the search box
2. Each group shows icon + title + description
3. Hover over results to see highlight
4. Click any result to go there instantly

## 🎯 What Happens When You Click a Result

✅ The correct tab/section opens automatically  
✅ The result is highlighted with a yellow flash  
✅ Page scrolls to show the highlighted item  
✅ Search closes and you're ready to work

## ⌨️ Keyboard Shortcuts

| Shortcut        | Action        |
| --------------- | ------------- |
| Cmd+K or Ctrl+K | Focus search  |
| Enter           | Submit search |
| Escape          | Close results |

## 💬 Example Workflows

### Find a Question About Networking

1. Press Ctrl+K
2. Type "network"
3. See all questions about networking
4. Click one → Goes to Questions tab, highlights it

### Search for Student Results

1. Click search bar
2. Type student name "Alice" or ID "2024015"
3. See all of Alice's exam results
4. Click result → Goes to Results tab, highlights the row

### Find Exam Details

1. Press Cmd+K
2. Type exam name "Biology Midterm"
3. See the exam with question count & duration
4. Click → Goes to Exams tab, opens that exam

## ❓ FAQ

**Q: Why is my search showing no results?**  
A: Check that you have data in that section (e.g., questions created, exams made)

**Q: Can I search multiple words?**  
A: Yes! Type your full phrase: "Windows operating system"

**Q: Does it search partial matches?**  
A: Yes, it finds any content containing your search term

**Q: Will it search case-sensitive?**  
A: No, search is case-insensitive

**Q: Can I search in one section only?**  
A: Not yet, but future versions could support this

## 🔧 Technical Details

- **Language**: JavaScript (ES6+)
- **Storage**: Uses browser localStorage
- **Performance**: Instant search as you type
- **Limit**: Shows up to 15 results (5 per type)
- **Integration**: Fully integrated with existing admin system
