Tournament Planner

Define how the tournament runs before launch.

How Tournament Mode Works
  • Global Target Mode: Sets the default game type for all rounds.
  • Per-Round Override: Each round can override mode with its own target game mode.
  • Game Selection: If games are selected for a round, only those games are eligible.
  • No round game selected: Any open game that matches that round mode remains eligible.

For each round: optionally set a different game mode, then select one or more game templates. Each selected template launches as a fresh tournament-only copy, so old completed, won, or lost session data never carries into the round.
