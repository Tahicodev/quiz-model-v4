Copy the exact question structure, generate in any chat AI, import back

① Copy the structure prompt (it matches the app's exact JSON format) → ② paste it into ChatGPT, Claude, Gemini… with your topic → ③ copy the model's JSON answer → ④ import it in Settings → Data → Import AI-Generated Questions. The app repairs and normalizes the JSON automatically.

Question structure guide

📐 Required question structure (what the model must output) Every generated question is a JSON object with question, type, options, answer, explanation, difficulty — the copy-prompt and server prompt both enforce this automatically.
  • multiple-choice — answer = exact option text
  • multiple-choice-multi — answer = options joined with " | "
  • true-false — answer = "true" / "false"
  • odd-one-out — answer = the odd option
  • draggable — answer = correct order, comma-joined
  • matching-pairs — answer = "Key-->Value|…" pairs
  • fill-blank — question uses [[1]], [[2]] placeholders; answer = words joined with "|"
  • code — adds codeSnippet, language, answerMode
Weaker models may output broken JSON — the app auto-repairs common issues on import, but recommended models give the best results.
