# 🎮 Games, Rules & Tournaments — Student Guide

Welcome! This guide explains **every game** you can play, **how to play it**, and
how **tournaments** work. Read it once and you will understand the whole app
philosophy: **learn by playing, get better by competing.**

---

## 1. The App Philosophy (the big picture)

This app is built around one simple idea:

> **You learn faster when it feels like a game.**

- **Practice** with fun game modes → you master the material.
- **Compete** against classmates → you stay motivated.
- **Win tournaments** → you get rewarded (points, EXP, badges).

```
                 ┌─────────────────────────────────────────┐
                 │            TEACHER / ADMIN              │
                 │  creates questions + builds a game      │
                 └────────────────────┬────────────────────┘
                                      │  gives you an ENTRY CODE
                                      ▼
    ┌─────────────────────────  YOU (STUDENT)  ──────────────────────────┐
    │                                                                   │
    │   Enter the code → join the lobby → ready up → game starts        │
    │                                                                   │
    │   ┌───────────────┐   ┌───────────────┐   ┌──────────────────┐    │
    │   │  Solo / 1v1   │   │  Team vs Team │   │   Tournaments    │    │
    │   │  play modes   │   │   (2 teams)   │   │  classes compete │    │
    │   └───────┬───────┘   └───────┬───────┘   └────────┬─────────┘    │
    │           │                  │                     │              │
    │           ▼                  ▼                     ▼              │
    │   Lightning Race      Card Battles           Single Elimination  │
    │   Sprint Race         Hot Potato             Round Robin         │
    │   Last Survivor       Card Draw              Swiss System        │

                          Points → Rewards → Champion!
```

> **Short version:** Questions come from a big question bank → games turn them
> into challenges → tournaments turn challenges into a championship.

## 2. How Every Game Starts

| Step | What happens |
| ---- | ------------ |
| 1. Join | Your teacher shares an **entry code** (6 letters/numbers, e.g. `AB3K9Z`). |
| 2. Enter | Type the code in your student space to enter the **lobby**. |
| 3. Ready | Wait for other players and press **Ready**. |
| 4. Start | When everyone is ready, the game starts automatically (or the teacher starts it). |
| 5. Play | Answer questions, earn points, follow that game mode's rules below. |
| 6. Result | A leaderboard shows the winner and your final score. |

Two match modes:

- **Solo Mode (1 vs 1 / Free-for-all)** — every player plays for themselves.
- **Team vs Team Mode** — players are split into **Team A** and **Team B**.
  Team scores are the sum of each member's points. In card battles the two
  teams play head-to-head. *(Optional rule: teams can **bet points** on their
  representative before each round.)*

Base settings (teacher can change them in the Game Studio):

| Setting | Default | Meaning |
| ------- | ------- | ------- |
| Points per correct answer | **10** | Points you earn for a right answer. |
| Question time limit | **20 s** | Time to answer in most games. |
| Turn time limit (cards) | **30 s** | Time per turn in card battles. |
| Math operators | `+`, `-`, `*` (1–12) | Backup math questions for duels. |

## 3. The 6 Game Modes

### 🏁 A. Lightning Race
*Best for: fast revision, whole class together.*

- All players answer **the same question at the same time**.
- The fastest correct answers earn the most points.
- A **streak multiplier** rule can be enabled: **3 correct answers in a row**
  puts you **"On Fire"** and doubles your points for that question.
- Most points when the questions finish → **winner**.

### ⚡ B. Sprint Race
*Best for: individual speed training.*

- A **global timer** (default 90 s) counts down for everyone.
- Answer as many questions as you can before the clock hits zero.
- Every correct answer adds points; wrong answers give nothing.
- With the **Bounty Bonus** rule, the player who ends the run ("the breaker")
  gets bonus points.
- Most points when the timer expires → **winner**.

### 🃏 C. Card Battle (Card Duel)
*Best for: head-to-head duels, 1 vs 1 or Team A vs Team B.*

- Each player (or team) has a **hand of cards**. Every card holds one question.
- On your turn you **send a card to your opponent** — they must answer it.
- If the **target answers correctly** → they earn the points.
- If the **target answers wrong (or runs out of time)** → the card is
  discarded and the **owner scores penalty points**.
- You may add **power-up cards** (next section) to complicate the duel.
- Run your opponent out of cards → you win.

### 🎴 D. Card Draw Battle
*Best for: tactical players who like surprises.*

- Same idea as Card Battle, but the **target pulls a card from the
  opponent's deck** and must answer it.
- Each player may answer a **limited number of questions** per game
  (an "answer limit").
- After every player reaches their answer limit, the game ends and the
  highest score wins.

### 🥔 E. Hot Potato Quiz
*Best for: fast, funny classroom energy.*

- One question is the **"potato"**. It is passed around the circle of players.
- Only the player currently holding the potato may answer, and they only have a
  few seconds (default **3 s per turn**, **15 s total** per question).
- Correct answer → the potato is "exploded": the question is solved and the
  smart player scores points.
- Wrong answer or time-out → the potato **moves to the next player**.
- Auto-rotate and a visual countdown keep the game moving.

### 💀 F. Last Survivor
*Best for: pressure and elimination suspense.*

- Everyone answers **the same question at the same time**.
- Answer **wrong → you are eliminated** (with the default "eliminate on first
  wrong answer" rule).
- Surviving players keep going until **only one player is left** or questions
  run out.
- The **last survivor wins a big bonus** (default +50 points).
- A reason is always shown so you know exactly why you were eliminated.

## 4. Power-up Cards (Card Battles only)

Power-ups make card duels strategic. The teacher decides which ones are
enabled. You play one when it matters.

| Card | What it does |
| ---- | ------------ |
| 🔁 **Mirror** | Reflects the question back at the attacker — if the target fails, the attacker loses double points. |
| ⏳ **Time Warp** | Cuts the opponent's timer down to ~5 seconds. |
| 🎲 **Double or Nothing** | Doubles the points at stake — you win double **or** you lose double. |
| 🛡️ **Shield** | Protects your card: the card is **not** discarded when the opponent misses. |
| ❄️ **Freeze** | Heavily reduces the target's remaining time. |
| 🕵️ **Steal** | If the target misses, you steal a random card from their hand. |
| 🌫️ **Fog** | Obscures the target's question UI — answering becomes harder. |
| 💥 **Combo Breaker** | Halves the reward the target would get, and boosts you when they miss. |
| ⚡ **Overclock** | Targets get a faster timer but **boosted points** if they still answer correctly. |

> **Card recharge:** used power-up cards can refill automatically — e.g. on a
> **3-question winning streak**, every **5 correct answers**, every **50 points**
> reached, or a **flash answer under 2 seconds**.

## 5. Optional Global Rules

These switches can be turned on for any game that fits:

| Rule | Effect |
| ---- | ------ |
| 🔥 **Streak Multiplier** | 3 correct answers in a row → "On Fire" → 2× points (Lightning Race). |
| 💰 **Bounty Bonus** | The player who breaks the run gets bonus points (Sprint Race). |
| 🎯 **Team Betting** | Teams bet points on their representative before a round (Team Mode). |
| 💀 **Sudden Death** | The **final 3 questions**: half the time, double the points. |
| 💡 **Hint Cost** | 50/50 hint costs you 50% of the points for that question. |
| ⏰ **Auto-play Timeout Card** | In card battles, if a player runs out of time, the game auto-plays a card for them (default ON). |

## 6. Tournaments 🏆

A tournament chains multiple games into one **championship** across several
rounds. Registration opens → players sign in → rounds happen → the best player
wins the crown.

### 6.1 Tournament formats

| Format | How it works |
| ------ | ------------ |
| ❌ **Single Elimination** | Lose one match → you are out. Half the players are eliminated every round. The last one standing is champion. |
| 🔁 **Round Robin** | Everyone plays everyone else. Points per match are added up. Highest total wins. |
| 🧩 **Swiss System** | No one is eliminated. After each round, players are matched with opponents of **similar scores**. The player with the most points after all rounds wins. |

### 6.2 Tournament settings (set by the teacher)

| Setting | Meaning |
| ------- | ------- |
| **Target Game Mode** | Which game types can be used (any, or a specific one like Card Battle). |
| **Rounds** | How many rounds the tournament runs (e.g. 4). |
| **Match Duration** | Minutes per match (e.g. 12). |
| **Best Of** | Win 1, 3, or 5 minigames to take the match. |
| **Point Multiplier** | Tournament points are multiplied (e.g. ×1 or ×2). |
| **Winner Bonus** | Extra points for winning a match (e.g. +100). |
| **EXP Bonus / Badge** | Prize at the end: bonus EXP and a badge name like "Tournament Champion". |
| **Auto Seeding** | Round-1 matchups are built from past performance (strong players don't meet in round 1). |
| **Allow Re-entry** | Late joiners can still enter until Round 2 closes. |

### 6.3 Tournament flow

```
RESULTS from Round 1  →  NEW MATCHUPS for Round 2  →  ...  →  FINAL
     └───────────────────────────────────────────────────┘
                     Winner = champion + reward
```

- The admin controls the event: **Start → Pause/Resume → Advance round → End**.
- You can follow a live **leaderboard** and the **round schedule** while you play.
