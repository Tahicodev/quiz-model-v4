## Approach: zero-logic reskin (CSS-first, minimal targeted markup)

All entity modals share one skeleton (`.modal` + `display` + `.active` class) and standard form classes (`.form-group .form-control .btn-primary`). So I can transform the look **without rewriting JS** — I restyle the shared chrome and add a scoped premium layer. This keeps every existing feature working while making it feel like a true SaaS product.

### 1. New premium design-system layer — `styles.css` (append-only, scoped)
Add an appended section (no edits to existing rules) with namespaced tokens + component styles:
- **Tokens**: `--qx-*` gradient (blue→indigo), glass surface, glow ring, deeper shadows, 14px radius scale, `Space Grotesk`-style heading treatment, focus-visible rings.
- **`.qx-drawer`** — slide-in panel (right, 520–560px, responsive→fullscreen modal on mobile), glass header with entity icon + title + "New/Edit" badge, sticky gradient-accent footer with primary action, animated slide/fade.
- **Premium field styles** (scoped under `.modal .modal-content` / drawer): floating-focus inputs, soft inner shadow, hover states, refined selects/toggles/checkbox chips.
- **Toolbar/table polish** for Categories/Exams/Classes/Games/Tournament list areas only (rounded table container, hover row lift, zebra subtle, refined search/sort inputs, icon buttons) — selectors scoped to those specific `#categories/#exams/#classes/#games` containers so other tabs are untouched.

### 2. Convert the 5 entity modals to drawers — `admin.html` markup (additive classes only)
For each of `#categoryModal`, `#examModal`, `#classModal`, `#userModal`, plus the two helper modals `#quickCategoryModal` / `#categoryAssignmentModal`:
- Add `qx-drawer` class + a premium header block (icon + title + status chip) and a sticky footer wrapper — purely additive; keep every existing `id`, `form`, and `onclick` intact.
- Add a per-entity SVG icon + gradient avatar.

### 3. New micro-interaction layer — `QxUI` (new `qx-ui.js`, loaded after legacy scripts)
A tiny vanilla-JS helper (no framework) that:
- Upgrades entity modals to drawer behavior: keeps their existing open/close fns working (they set `display` + `.active`), adds backdrop click-to-close, ESC-to-close, focus trap, and slide animation hook.
- Adds button ripple + loading spinner on submit buttons.
- Auto-wires all `[data-tab]`/sub-tab buttons with a smooth active-state transition.

### 4. Games & Tournament studios (currently inline forms, not modals) — `admin.html` + CSS
Reskin into SaaS "control panel" cards:
- Games/ Tournament sub-tab bars → premium segmented control (glass pill, sliding active indicator).
- `#gameForm` panel and Tournament "Planner" → elevated glass card, section dividers, refined switches, gradient "Create/Save" primary button, "Reset" ghost button.

### 5. Student workspace — `student-workspace.html` + CSS
Polish (features untouched): premium header/profile dropdown, elevated workspace panels, hero stat cards with gradient numbers + lift hover, refined tab strip, and restyle `studentProfileModal` + `studentAuthModal` + `studentGameModal` to the new drawer/premium-modal system.
