All four bridges were chosen; the browser-verified ground truth changed the shape of two of them, so here is what is actually possible:

- **Auto-detect needs no backend change.** The player can already discover which championships a game belongs to: `GET /api/v1/kids/championships/browse?status=active` (auth, STUDENT allowed, scoped to their own teachers) returns `game_ids`. Scoring is already wired: the existing session-complete `PATCH` writes the championship score **only because** the player echoes `championship_id` (`kids.routes.js:106-117`), and the server re-grades first (`KidsChampionshipService.recordScore`).
- **The podium card has real data.** `recordScore` returns `{ recorded, improved, points, leaderboard, my, finished }`, and `my` is a full standings row — so neighbours, rank and medal are all derivable client-side.
